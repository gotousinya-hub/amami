# 株式会社奄美 コーポレートサイト

株式会社奄美のリニューアル用トップページです。`index.html` をブラウザで直接開くか、プロジェクトフォルダで静的サーバーを起動して確認できます。

## HPとして見る方法

### 方法1: `index.html` を直接開く

Finderやエクスプローラーでこのフォルダを開き、`index.html` をダブルクリックしてください。

### 方法2: ローカルサーバーで見る（おすすめ）

ターミナルで必ずこのプロジェクトフォルダに移動してからサーバーを起動します。

```bash
cd /workspace/amami
python3 -m http.server 4173
```

その後、ブラウザで以下を開きます。

```text
http://127.0.0.1:4173/index.html
```

または以下でも表示できます。

```text
http://127.0.0.1:4173/
```

## 「Directory listing for /」が表示される場合

`127.0.0.1:4173` でフォルダ一覧が表示されている場合は、サーバーを起動した場所がこのプロジェクトフォルダではありません。
スクリーンショットのように `.cache/` や `.config/` などが並ぶ場合は、ホームディレクトリでサーバーが起動しています。

一度サーバーを `Ctrl + C` で止めてから、以下の順番で起動し直してください。

```bash
cd /workspace/amami
python3 -m http.server 4173
```

ブラウザは以下を開いてください。

```text
http://127.0.0.1:4173/index.html
```

## 本番公開する場合

サーバーの公開ディレクトリ（例: `public_html`、`www` など）に以下をアップロードしてください。

- `index.html`
- `styles.css`
- `script.js`
- `assets/`

`README.md` は確認用の説明ファイルなので、本番公開には必須ではありません。

## 構成

- `index.html` - ページ構造
- `styles.css` - レスポンシブ対応を含むビジュアルスタイル
- `script.js` - ヘッダー状態とモバイルメニュー制御
- `assets/` - 奄美の海と施工品質をイメージしたSVGビジュアル
